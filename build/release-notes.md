# SuperMask 超级面具 v1.2.1

> **设计变更**：按需求落地"面具之后 Chrome 无法登录"——面具浏览器**刻意禁止账号登录**，配置永远退出即焚。同时修复 Chrome 强制全量代理下的两个隐藏问题（垃圾标签页 + 注入竞态）。

给 Windows 浏览器戴上"地理位置面具"：**GPS 坐标 / 时区 / 语言 / WebRTC** 一键伪装，**自动同步 VPN 出口**，**强制全量走 VPN**，**运行时注入、不改系统文件、关闭即恢复**。

## v1.2.1 更新内容

### 🔒 面具浏览器禁止登录账号（设计变更）

登录会把你的真实身份与面具指纹/出口绑定，让伪装失去意义。v1.2.1 起：

- **网络层屏蔽 Google 账号登录页**（accounts.google.com / accounts.youtube.com 等）——打开即被替换为"登录已禁用"提示页，控制器每 2 秒强制重新执行（对抗 Google 重定向链），登录表单永远无法使用
- **移除"保留配置文件"选项**：面具配置永远退出即焚，无任何登录状态/Cookie 可存留
- 好处：杜绝"账号关联"这一最常见的匿名性破绽

### 🐛 修复：--host-resolver-rules 参数被拆裂产生垃圾标签页

参数值含空格，经命令行字符串传递时被 Chrome 拆成多个参数，导致**每次启动开出 4 个垃圾标签页**（`*`、`EXCLUDE`、`~NOTFOUND,`、`127.0.0.1`），且该参数从未真正生效。已移除——显式代理下 Chrome 自动把主机名交给代理解析（DNS 不落地），本就无需它。

### 🐛 修复：控制器轮询可能被无限期阻塞

WebSocket 连接/发送补齐超时（3 秒），避免某个标签页销毁/挂起时卡死整个控制器循环。

## 既有功能（v1.2.0 / v1.1.x 累积）

- **自动同步 VPN 出口**：读取系统代理探测出口 IP，坐标/时区/语言全自动一致
- **强制 VPN 模式**：SOCKS5 自动发现（相邻端口握手探测）+ 禁 QUIC/HTTP3 + JS 层禁用 WebRTC + 显式代理全协议，代理断开即断网不回退
- **WebRTC 泄漏检测**：「验证伪装」用多路 STUN 实测公网映射 IP 并与出口比对
- **完整恢复闭环**：停止还原 / 崩溃恢复 / 开机守卫 / 独立紧急恢复

## 使用方法

1. **先启动 VPN/代理**，再运行 `SuperMask.exe`（zip 请先解压再运行）
2. 地点保持「自动 · 同步VPN/代理出口(推荐)」，强制VPN模式保持勾选
3. 点 **▶ 启动面具** → 在弹出的独立面具浏览器里正常上网（不要在里面登录任何账号——登录页会被自动屏蔽）
4. 点 **✓ 验证伪装** 确认时区/语言/坐标/WebRTC 四项全 [OK]
5. 用完点 **■ 停止并恢复**，或直接关闭面具浏览器窗口

杀毒软件拦截时：右键文件 → 属性 → 解除锁定；或加白名单；或用 Source code（zip）+ `StartSuperMask.bat` 源码方式运行。
