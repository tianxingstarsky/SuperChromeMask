# SuperMask 超级面具 v1.2.0

> **Chrome 专精 · 强制全量走 VPN**：面具浏览器的**全部流量**（网页 / DNS / 后台连接 / WebRTC / QUIC）强制经 VPN，无直连旁路；代理断开即断网，**绝不静默回退直连**。

给 Windows 浏览器戴上"地理位置面具"：**GPS 坐标 / 时区 / 语言 / WebRTC** 一键伪装，**自动同步 VPN 出口**，**运行时注入、不改系统文件、关闭即恢复**。

## v1.2.0 更新内容：强制 VPN 模式（Chrome 专精）

针对"Chrome 还有哪些流量可能绕过代理直连"做了穷尽式封堵，勾选后（默认勾选）：

1. **自动发现 SOCKS5 端口**：自动探测系统代理端口及其相邻端口（v2rayN 等客户端常见 socks=http-1 布局），必须通过 SOCKS5 握手验证才采用 → SOCKS5 可承载 UDP、远端解析 DNS，是最彻底的代理形态；找不到则回落 HTTP 代理。可在"代理"框手动指定（支持 `socks5://host:port`）。
2. **禁 QUIC/HTTP3**：`--disable-quic` 堵住 UDP 443 直连旁路（HTTP 代理管不住的泄漏点）。
3. **JS 层禁用 WebRTC**：网页无法发起 STUN 探测（v1.1.1 修复，实测 Chrome 153 在 HTTP 代理下会绕过 UDP 策略直连 STUN 暴露真实 IP）。
4. **显式代理强制全协议**：网页/DNS/后台连接全部经 VPN；**代理挂掉 = 页面直接断网**，Chrome 不会静默回退直连——宁断不漏。

实测（本机 Chrome 153 + 系统代理 18081/SOCKS5 18080）：

```
强制VPN模式: 面具浏览器全量代理 → socks5://127.0.0.1:18080 [SOCKS5,可承载UDP]
面具浏览器内页面真实公网IP: 38.106.19.252 (洛杉矶VPN出口)
WebRTC 泄漏检查: 无公网候选(WebRTC已禁用) [OK]
时区/语言/地理API: 全部 [OK]
```

## 使用方法

1. **先启动 VPN/代理**，再运行 `SuperMask.exe`（zip 请先解压再运行）
2. 地点保持「自动 · 同步VPN/代理出口(推荐)」；"强制VPN模式"保持勾选
3. 点 **▶ 启动面具** → 在弹出的独立面具浏览器里正常上网（日志会显示全量代理走向）
4. 点 **✓ 验证伪装** 确认时区/语言/坐标/WebRTC 四项全 [OK]
5. 用完点 **■ 停止并恢复**，或直接关闭面具浏览器窗口

## 关于"针对日常使用的 Chrome"

Chrome 136+ 出于安全禁止在默认用户目录上开启远程调试，因此 GPS/时区/语言级伪装只能作用于**独立配置目录**的 Chrome 实例（本工具的做法）。需要"自己的、可登录的面具 Chrome"：勾选「保留面具配置文件」——该配置持久保存，可在里面登录 Google 账号，下次启动复用同一身份。

如果杀毒软件拦截 exe：右键文件 → 属性 → 勾选"解除锁定"；或加白名单；或用 Source code（zip）+ `StartSuperMask.bat` 源码方式运行。
